# DevLinks Pro (Frontend Only)

Simple React + Vite app implementing a Linktree-style profile editor with live preview, dark mode, animations, and localStorage persistence.

Setup

1. Install dependencies:

```bash
cd C:\Users\arjam\devlinks-pro
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes
- Tailwind CSS is configured via `tailwind.config.cjs` and `postcss.config.cjs`.
- Components live in `src/components` and the main page is `src/pages/Home.jsx`.
